## Contributing

Pull requests are welcome. The whole process is:

1. **Fork** the repository you want to improve.
2. **Clone** your fork and create a branch:

   ```bash
   git clone https://github.com/<your-username>/<repo>.git
   cd <repo>
   git checkout -b my-change
   ```

3. **Make your change** and commit it with a clear message.
4. **Push** your branch and **open a pull request** against the original repository.

Found a bug or have an idea? Open an issue in the relevant repository. If you're not sure where it belongs, email us at [tech@bwrld.uk](mailto:tech@bwrld.uk).
